    Alibaba Cloud Model Studio:CosyVoice voice list

    Last Updated:Sep 28, 2026

    System voices for CosyVoice are listed below. For custom voices, use the voice cloning feature (free). See Use a cloned voice for speech synthesis.

    When you synthesize speech:

    • Each model supports a specific set of voices. Voices are not interchangeable between models.
    • Synthesis text must match the voice's supported language. Mismatches cause pronunciation errors or unnatural output.
    • For SSML-supported voices, enter SSML-compliant content in the text request parameter. See Introduction to SSML.
    • For Instruct-supported voices, enter Instruct-formatted text in the instruction request parameter.
    • For timestamp-supported voices, enable this feature using the word_timestamp_enabled request parameter (or enableWordTimestamp in Java SDK).

    Click to view Instruct settings

    Instruct text must be in Chinese. Follow the exact format below, including punctuation marks. Do not omit the period at the end. Supported emotion values: neutral, fearful, angry, sad, surprised, happy, disgusted.

    1. Set emotion

      • Format: "你说话的情感是<情感值>。"
      • Example: "你说话的情感是neutral."

    2. Set scenario and emotion

      • Format: "你正在进行<场景>，你说话的情感是<情感值>。"
      • Example: "你正在进行闲聊互动，你说话的情感是neutral."
      • Supported scenarios: 闲聊互动 (casual conversation), 新闻播报 (news broadcast), 广告促销 (ad promotion), 比赛解说 (sports commentary), 一些儿童内容解说 (commentary for children's content), 语音导航 (voice navigation), 脱口秀表演 (stand-up comedy).

    3. Set role and emotion

      • Format: "你现在说话的角色是<角色>，你说话的情感是<情感值>。"
      • Example: "你现在说话的角色是一个旁白，你说话的情感是neutral."
      • Supported roles: 一个旁白 (narrator).

    4. Set identity and emotion

      • Format: "你正在以一个<身份>的身份说话，你说话的情感是<情感值>。"
      • Example: "你正在以一个故事机的身份说话，你说话的情感是neutral."
      • Supported identities: 故事机 (storytelling machine).
