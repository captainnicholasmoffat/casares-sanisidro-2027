How does image editing differ from Text to Image generation?
Text to Image generation creates entirely new images from text descriptions, while image editing modifies existing images based on instructions. Image editing models take both an input image and editing instructions, then produce a modified version of the original image.
How are image editing models ranked?
Models are ranked using an Elo rating system derived from blind comparisons judged by our recruited human panel, together with public Image Arena votes cast before 1 January 2026. Voters compare edited outputs from the same input image and editing instruction, choosing the result they prefer. Higher Elo scores indicate a model is preferred more often.
