# Beyond Presence Studio

> Beyond Presence Studio (bey.studio) is the creator platform for Beyond Presence. Creators use it to build and deploy hyper-realistic, real-time AI avatar agents: create custom avatars, design conversational agents, generate videos from text, manage knowledge bases, and handle billing and team settings from one dashboard. Everything built in Studio is also available programmatically through the Beyond Presence developer API.

Beyond Presence builds real-time, hyper-realistic AI video avatars for conversational applications. Studio is the no-code dashboard where creators produce and manage the avatars and agents that power those experiences, while developers can access the same capabilities through the API and SDKs. Agents stream in 1080p with frame-accurate lip-sync, natural head movement, and ultra-low latency (<250ms globally), and support multilingual interactions on enterprise-grade infrastructure (GDPR and SOC 2 Type II compliant).

## Features

- [Avatars](https://bey.studio/avatars): Create custom avatars and use ready-made stock avatars.
- [Agents](https://bey.studio/agents): Design conversational AI agents with built-in avatars, voice, and memory.
- [Text to Video](https://bey.studio/videos): Generate realistic avatar videos from text scripts.
- [Knowledge Base](https://bey.studio/knowledge): Ground agents in your own documents and content.
- [Conversations](https://bey.studio/conversations): Review and analyze agent conversations.
- [Analytics](https://bey.studio/analytics): Track usage and engagement across agents.
- [API Keys](https://bey.studio/settings/api-keys): Generate keys to access Beyond Presence programmatically.

## Developer API

- [Developer Docs](https://docs.bey.dev/): API reference, SDKs, and integration guides for Beyond Presence.
- Speech-to-Video API: Convert an audio stream into a real-time, hyper-realistic avatar video.
- Managed Agents API: Deploy end-to-end conversational AI agents with built-in avatars, voice, and memory.
