# Credits and Subscriptions

> How LiveAvatar billing and credit deductions work

## Credit rates

| Mode | Cost |
| - | - |
| Embed / FULL Mode | 2 credits per minute |
| Avatar Only (LITE mode) | 1 credit per minute |

### How credits are deducted

Sessions cannot start without sufficient credits for at least one minute.

LiveAvatar charges per minute of session time. The system checks all concurrent active sessions every minute and deducts credits based on the mode and elapsed duration.

<Info>
  Unlike HeyGen's previous approach, LiveAvatar starts the session before enabling client token generation, so you're not metered during frontend setup.
</Info>

### Overage billing

If you need more credits, toggle on overage in your settings. You are charged for each additional credit consumed. Each plan has a different overage rate.

Without overage, sessions automatically end when your credit balance is exhausted and you cannot start new ones. With overage enabled, sessions do not end automatically and you can continue starting new sessions.

For higher-volume needs, contact [support@liveavatar.com](mailto:support@liveavatar.com).
