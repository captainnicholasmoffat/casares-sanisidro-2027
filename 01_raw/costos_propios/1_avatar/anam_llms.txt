# Anam

> Real-time conversational AI avatars for human-like digital interactions

Anam provides streaming AI personas that can see, hear, and speak in real-time.
Our technology powers customer support, education, sales training, and healthcare applications.

This file (https://anam.ai/llms.txt) is the canonical entry point for AI agents.
For full developer documentation, see the docs resources linked under
"Documentation for AI agents" below.

## What We Do

Anam creates AI avatars that have natural conversations. Unlike pre-recorded video,
our avatars respond in real-time with sub-second latency (750ms-2s end-to-end).

## Key Capabilities

- Real-time streaming: Live video generation, not pre-recorded clips
- Low latency: 750ms-2s response time
- 50+ languages: Multilingual support out of the box
- Interruption handling: Natural conversation flow
- Custom avatars: Use stock or create custom personas
- Multiple voices: Cartesia and ElevenLabs integration

## Integration Options

- Turnkey: Full pipeline (STT -> LLM -> TTS -> Avatar)
- BYO LLM: Bring your own language model
- LiveKit: Face-only for existing LiveKit agents
- JavaScript SDK: npm install @anam-ai/js-sdk
- React SDK: npm install @anam-ai/react

## Use Cases

- Customer support: 24/7 video-based support agents
- Sales enablement: Training and role-play simulations
- Education: Interactive tutoring and language learning
- Healthcare: Patient intake and triage
