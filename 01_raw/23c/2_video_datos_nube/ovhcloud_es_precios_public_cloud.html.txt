 Data Platform de OVHcloud ofrece una tarificación basada en cuatro aspectos: la potencia de cálculo dedicada a la ejecución de consultas, el tratamiento de datos, el alojamiento de aplicaciones y el volumen de datos almacenados.
 La unidad de potencia de cálculo utilizada para realizar tratamientos de datos y alojar aplicaciones es la Data Platform Unit (DPU), correspondiente a 1 vCPU y 4 GB de RAM.
 Con Data Platform de OVHcloud, la facturación se realiza por organización y no por usuario. De este modo, podrá añadir tantos trabajadores y usuarios finales como desee dentro de su organización.

 Con este modelo por uso, la facturación se basa en:
 el número de TB de datos tratados por cada consulta, tanto si se realizan en el Data Lakehouse como en Direct Query (hacia datos fuera de Data Platform) desde el Analytics Manager;
 el número de DPU utilizadas para realizar acciones con los servicios Data Processing Engine o Application Services. El uso se mide por segundos y se factura por horas.
 Para cada una de sus acciones o aplicaciones, puede aumentar el número de DPU asignadas para acelerar la ejecución y mejorar la fiabilidad del tratamiento.
 La tarificación del almacenamiento corresponde al coste de conservación de los datos que cargue en el Data Lakehouse de la Data Platform, medido en gigabytes (GB) de datos almacenados. OVHcloud no cobra ningún coste adicional por la transferencia de datos (entrante y saliente).
