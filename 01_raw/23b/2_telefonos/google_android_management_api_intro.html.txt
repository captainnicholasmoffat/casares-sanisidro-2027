 La API de Android Management está disponible como parte de Android Enterprise , una iniciativa que proporciona a los desarrolladores herramientas para compilar soluciones que permitan a las organizaciones administrar sus flotas de dispositivos Android. El
está dirigido a proveedores de administración de movilidad empresarial (EMM). Para implementar una solución de producción que use la API de Android Management, los EMM deben seguir los pasos que se describen en Cómo lanzar tu solución .
 Puedes usar la API de Android Management para admitir la
 perfil de trabajo en un dispositivo de propiedad personal 
 perfil de trabajo en un dispositivo empresarial ,
un dispositivo completamente administrado 
y conjuntos de soluciones para dispositivos exclusivos .
 Consulta la Guía de inicio rápido para probar la API.
 Cómo funciona
 La API de Android Management admite la administración completa de movilidad empresarial
de Google Cloud, desde la inscripción inicial de los clientes hasta la configuración y administración de dispositivos.
 Como desarrollador de EMM, proporcionas a tus clientes una solución local
Consola de EMM En la consola, los clientes generan tokens de inscripción de dispositivos.
y crear políticas de administración. Usan los tokens para inscribir dispositivos y aplicar políticas de administración a los dispositivos que inscribieron.
 En el backend, tu consola usa la API de Android Management para crear
tokens de inscripción, políticas y otros recursos de administración. Durante la inscripción,
en cada dispositivo se instala la aplicación complementaria de la API
 Android Device Policy .
Cuando las políticas se vinculan a un dispositivo en la API, Android Device Policy
aplica la configuración de la política en el dispositivo.
 Nota: Android Device Policy es el único controlador de política de dispositivo compatible
con la API de Android Management. 
 Recursos de la API
 En esta sección, se describen los recursos principales que se usan en la API de Android Management.
 Empresas
 Por lo general, un recurso enterprises representa una sola organización. Crea una empresa como parte de un flujo de configuración en línea que tus clientes usan para vincular su organización con tu solución de EMM. Las políticas, los tokens de inscripción y los dispositivos pertenecen a una empresa.
 Políticas
 La API de Android Management sigue un modelo basado en políticas. R
 policies 
contiene un grupo de configuraciones de administración de aplicaciones y dispositivos que rigen la
de un dispositivo. El rango y la flexibilidad de la configuración admitida en policies te permiten configurar dispositivos para una variedad de casos de uso diferentes.
 Consulta Crea una política para obtener más información.
 Tokens de inscripción
 Usas enrollmentTokens para vincular dispositivos a una empresa, un proceso llamado inscripción y aprovisionamiento.
De manera opcional, los tokens de inscripción pueden contener detalles adicionales (p. ej., credenciales de Wi-Fi corporativas), un policyName vinculado a un recurso policies y un identificador de cuenta de usuario.

 La API de Android Management simplifica la administración de usuarios. Puedes inscribir un dispositivo con o sin especificar un usuario en el token de inscripción.
 Si no especificas un usuario, se creará uno nuevo automáticamente.
 Si especificas un usuario existente, este se asociará con el dispositivo. Puedes asociar un usuario con hasta 10 dispositivos.
