 RCS
 Send verified, branded messages with pay-as-you-go pricing based on destination country. RCS messages are charged only upon delivery, with pricing that varies by message type and country.
 United States RCS Messaging
 In the US, RCS messages are classified as Rich or Rich Media based on content. Rich messages are billed per 160-byte (UTF-8) segment. Rich Media messages are billed at a flat rate per message. Each message has two cost components: a transport fee and a carrier fee. Businesses are only charged when a message is successfully delivered.

 Rich RCS includes: 
 • Text (billed per 160-character segment) 
 • Suggested replies 
 • Suggested action: Dial a phone number• Suggested action: Open URL (full browser)
 Rich Media RCS includes: 
 • Rich cards or carousels 
 • Media file attachments (images, video, audio) 
 • Suggested action: Open URL in a webview 
 • Suggested action: View location or Share location 
 • Suggested action: Create calendar event
 Message classification is automatic based on content. Suggested replies, Dial, and Open URL can be added to any message type without changing its classification. Any media, rich card, carousel, or advanced action upgrades the message to Rich Media.
 International RCS Messaging
 Outside the US, RCS messages are billed per message or per conversation. Messages up to 160 characters are billed as RCS Basic. Messages over 160 characters, or containing rich cards, file attachments, carousels, or any suggestion added to any message type are billed as RCS Single. Businesses are only charged when a message is successfully delivered.

 RCS Conversation Pricing 
 Conversational pricing requires: 
 • The RCS agent must be registered as a Conversational agent at the time of creation 
 • The business must both send and receive a message to/from its end user within a 24-hour window 
 • Once both conditions are met, all subsequent messages within the 24-hour window are included in the conversational rate
 If either condition is not met, messages are billed individually as Basic or Single. For full conversation session rules, refer to the AWS End User Messaging RCS developer documentation.

 SMS
 The price for sending SMS messages varies between countries and regions, and in some cases, between carriers in the same country or region. These prices change regularly.
 Carrier fees will vary based on the type of number sending the message. See FAQs for more information on carrier fees.
 To qualify for the local route price, you must comply with India specific regulations. The default route to India is via International Long Distance Operator (ILDO) routes. For more information please refer to AWS End User Messaging .
 For international sends (e.g., sending messages from a different country phone number than the destination country number), the cost per message will be charged based on the destination country price.
 Messages sent to Canada via a toll-free number will be charged $0.00581 per message fee and $0.00705 carrier fee.

 WhatsApp
 WhatsApp
 AWS charges two fees for each WhatsApp message: 
 1.  AWS message fee: $0.005 per outbound message globally (except India Authentication and Utility messages at $0.002), and $0.001 per inbound message globally.
 2. Meta message fee: price varies for each country and message type. 
 The Meta message fee is set by Meta and subject to change by Meta. We will make reasonable efforts to notify you of increases to the Meta message fee.
 We implement Meta's volume-tiered pricing for Meta message fee. The volume-tiered prices, tier thresholds, and discounts are set by Meta, and subject to change by Meta. Volume tiers on ongoing monthly usage are determined solely by Meta. AWS applies the volume tiers to ongoing usage as and when Meta informs us of tier changes. For more information about tier thresholds and current rates, see Meta's WhatsApp Business Platform pricing documentation . 
 AWS charges the Meta message fee using the rates in Meta's INR rate card, including for volume-tiered pricing. AWS will charge the Meta message fee in USD by applying the INR to USD exchange rate as of 7/1/2026. On the first day of each quarter, AWS may update the USD price it charges for the Meta message fee to reflect changes to the INR to USD exchange rate.
 Message types are:
 Marketing  — Enables you to achieve a wide range of goals, from generating awareness to driving sales and retargeting customers. Examples include new product, service, or feature announcements, targeted promotions/offers, and cart abandonment reminders.
 Utility  — Enables you to follow-up on user actions or requests. Examples include opt-in confirmation, order/delivery management (e.g., delivery update), account updates, alerts (payment reminder), and feedback surveys.
 Authentication  —  Enables you authenticate users with one-time passcodes, potentially at multiple steps in the login process (e.g., account verification, account recovery, integrity challenges). Authentication also includes the Authentication-International message type that applies to countries with international sending rates. See https://developers.facebook.com/docs/whatsapp/pricing/authentication-international-rates to see if these international rates apply to your business.
 Service  — Enables you to resolve customer inquiries.

 WhatsApp Voice Calling
 AWS charges two fees for each minute of a WhatsApp voice call:
 AWS voice calling fee: $0.005 per minute for outbound (business-initiated) calls globally (except India at $0.003 per minute), and $0.001 per minute for inbound (user-initiated) calls globally.
 Meta connectivity fee: price varies for each country. The Meta connectivity fee is charged on outbound (business-initiated) calls only; inbound (user-initiated) calls are free of the Meta connectivity fee.
 The Meta connectivity fee is set by Meta and subject to change by Meta. We will make reasonable efforts to notify you of increases to the Meta connectivity fee.
 We implement Meta's volume-tiered pricing for the Meta connectivity fee. The volume-tiered prices, tier thresholds, and discounts are set by Meta, and subject to change by Meta. Volume tiers on ongoing monthly usage are determined solely by Meta. AWS applies the volume tiers to ongoing usage as and when Meta informs us of tier changes. For more information about tier thresholds and current rates, see  Meta's WhatsApp Business Platform pricing documentation .
 AWS charges the Meta connectivity fee using the rates in Meta's INR rate card, including for volume-tiered pricing. AWS will charge the Meta connectivity fee in USD by applying the INR to USD exchange rate as of 7/1/2026. On the first day of each quarter, AWS may update the USD price it charges for the Meta connectivity fee to reflect changes to the INR to USD exchange rate.
 Billing is per minute, metered in 6-second pulses rounded up to the next pulse (10 pulses = 1 minute). Billing starts when the call is answered; unanswered calls are not billed. Business-initiated (outbound) calling is unavailable in the United States, Canada, Egypt, Vietnam, and Nigeria. User-initiated (inbound) calling is available in all countries where the WhatsApp Cloud API is available.
 Call types are:
 Business-initiated call (BIC)  — an outbound call placed by the business to a customer. Requires the customer's call permission.
 User-initiated call (UIC)  — an inbound call placed by a customer to the business

 Push notifications
 You pay $0 for the first 1,000,000 push notifications that you send each month, and $0.000001 for each push notification that you send after that.
 Voice
 Voice (outbound only)
 The price for sending voice messages varies between countries, and occasionally between carriers within the same country or region. These prices are subject to change.
 To send voice messages using AWS End User Messaging, you must obtain at least one dedicated, voice-enabled long code. You can lease local phone numbers in a variety of countries directly through the AWS End User Messaging console. A long code is a standard telephone number that your message is sent from.
 Note: Pricing differs for voice-enabled long codes vs. SMS-enabled long codes. You can’t use voice-enabled long codes to send SMS messages unless the phone number also has SMS enabled. SMS-enabled long codes are not available in all countries, and are often more expensive than voice-enabled long codes.

 Notify
 Notify is a managed notification feature that lets developers send templated messages such as one-time passcodes (OTP) without requiring their own phone numbers. Start sending in minutes with AWS-managed numbers, SMS Protect built-in, and multi-language template support.
 Notify
 Notify pricing has two components charged per message sent:
 Notify fee : Starting at $0.045 per message sent (with volume tiers below) — covers managed numbers, template management, route optimization, and SMS Protect.
 Channel fee : Varies by channel and destination country — same as standard AWS End User Messaging channel pricing. 
      Total cost per message = Notify fee (volume-tiered, starting at $0.045) + Channel fee (varies by country)

 Phone Numbers
 Numbers
 Simulator numbers
 Simulator numbers are test phone numbers used to send messages to other simulator numbers. When you send a message from a simulator number, you pay the standard outbound SMS or MMS messaging rate. Simulator numbers can be purchased in the AWS End User Messaging SMS console for a monthly lease price of $1. 
 10-digit long code (10DLC) phone number
 10DLC is a 10-digit phone number used only in the United States. In order to use a 10DLC number you'll need to first register your company and create a 10DLC campaign through the AWS End User Messaging console. Afterwards, you can associate a 10DLC number with your 10DLC campaign. For more information, visit our 10DLC page . 
 There are required registration and monthly fees associated with using 10DLC.
 Company related fees:
 Company registration: $4.50 one-time fee per company. If you resubmit your company (e.g. Company name, EIN), it will be assessed a $4.50 resubmission fee.
 Company authentication plus verification email fee: $12.50 one-time per company, applicable to public profit brands. If you resubmit for verification, it will be assessed a $12.50 email fee.
 Company vetting fee: $41.50 one-time-fee per vetting request.
 Campaign related fees:
 10DLC campaign registration: $50 one-time campaign activation fee required by T-Mobile. This fee will be postponed until further notice.
 10DLC campaign monthly: $10 per regular 10DLC campaign, $2 per low-volume 10DLC campaign. 
 Phone number related fees:
 10DLC phone number monthly: $1 per 10DLC phone number. 
 Toll-free phone number
 A toll-free is a 10-digit number used that begins with one of the following three-digit codes: 800, 888, 877, 866, 855, 844, or 833. Currently AWS End User Messaging only supports SMS-enabled toll-free numbers in the United States. Toll-free numbers can be purchased on the AWS End User Messaging console with a monthly lease price of $2. 
 Long code phone number
 A long code is a standard phone number (10-digit in many countries) used to send and receive voice calls and SMS messages. A long code is always required to send a voice message, but is not always required to send an SMS message as countries support different forms of origination identities for SMS.  Please see the Supported countries and regions page to learn more about SMS origination identity support by country. Long codes not listed in the table below can be requested through AWS Support .  Carrier Lookup 
 You can use Carrier Lookup to improve the delivery rates of the SMS messages you send through AWS End User Messaging. Carrier Lookup helps identify errors that often occur when your customers enter their phone numbers on web-based forms.
 Carrier Lookup also provides important information about your customers’ phone numbers. For example, it can tell you if a phone number is a landline, or a mobile number or the carrier or country a phone number belongs to. You can use this information to make sure that you send messages using the right channel. Note, customers leveraging the previous phone number validate capability pay the same price per request.
 You pay $0.006 for each Phone Number Validate request. 
 One-Time Password (OTP)
 AWS End User Messaging includes a One-Time-Password (OTP) feature. You can use this feature in your applications to authenticate your users during the sign-up process or when they log in. AWS End User Messaging generates a 6- to 8-digit code, and sends the code as an SMS message. You can then call the AWS End User Messaging API to verify that the code the user entered matches the code that was generated. You pay $0.045 for each successful OTP verification, in addition to the standard per-message price for sending SMS messages.
