API Transporte Público

Jefatura de Gabinete de Ministros. Secretaria de Transporte y Obras Públicas

API con información en tiempo real de trenes, colectivos, subte y cortes de tránsito en la Ciudad. Se informa a los usuarios de BA DATA que todos los datasets con Formato API y GTFS, están suspendidos. Se encuentran en revisión y corrección. Una vez reanudado el servicio se informará a la comunidad.
